# Papers

This directory contains individual research articles, organized chronologically by publication year.

Each subfolder (e.g., `/1986-Connexions-et-Diffeologie/`) contains:
- The TeX source file(s)
- Figures (if any)
- A compiled PDF (when available)

All papers are included under the CC BY 4.0 license. Use and adaptation are permitted with attribution.

For a complete list of papers and their abstracts, see the main README at the root of the repository.
