# Diffeology (Beijing Revised Edition)

**Status:** Canonical Reference (Updated Sources)
**Original Publication:** Beijing World Publishing Corporation (2022)
**Last Source Update:** December 2025

## Context
This directory contains the **Revised Edition** of the monograph *Diffeology*. It supersedes the 2013 AMS edition.

## 2025 Update
The source files in this directory have been updated by the author (Patrick Iglesias-Zemmour) in December 2025 to correct minor misprints and errors found in the printed Beijing edition (specifically regarding integration bundles and groupoid isotropy).

**This version represents the most accurate and up-to-date text of the theory available.**
